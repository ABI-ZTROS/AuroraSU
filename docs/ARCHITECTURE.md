# AuroraSU 架构设计文档

## 概述

AuroraSU 是一个融合多种先进技术的 Android 内核级 Root 解决方案，旨在提供**极致稳定性**、**丰富功能**和**精美体验**。

## 设计理念

### 核心原则
1. **稳定性优先**: 多重冗余保护机制，确保系统安全可靠
2. **功能丰富**: 融合各方案优点，提供完整的 Root 体验
3. **自适应**: 根据设备特性自动选择最佳工作模式
4. **现代化**: Material You 设计，动态主题支持

## 核心组件

### 1. 内核模块 (Kernel Module)

#### 1.1 初始化系统 (core/init.c)
- **功能**: 模块加载、功能检测、子系统初始化
- **特性**:
  - 自动检测 GKI/非 GKI 设备
  - 动态选择 Hook 模式 (kprobe/manual/hybrid)
  - 支持 late-load 和 built-in 两种加载方式

#### 1.2 超级调用接口 (supercall/)
- **功能**: 用户空间与内核通信
- **接口**:
  - `AURORA_IOCTL_GRANT_ROOT`: 授予 Root 权限
  - `AURORA_IOCTL_GET_INFO`: 获取版本和功能信息
  - `AURORA_IOCTL_SET_SEPOLICY`: 动态 SELinux 策略
  - `AURORA_IOCTL_KPM`: KPM 模块管理
  - `AURORA_IOCTL_GET_REDUNDANCY`: 冗余状态查询

#### 1.3 钩子管理系统 (hook/)
- **双模式设计**:
  - **Kprobe 模式**: 适用于 GKI 设备，使用 tracepoint
  - **Manual Hook 模式**: 适用于非 GKI 设备，直接修改 syscall 表
  - **Hybrid 模式**: 同时使用两种机制，提供冗余

### 2. KPM 2.0 (Kernel Patch Module)

#### 2.1 设计改进
- **热补丁支持**: 无需重启即可加载/卸载
- **签名验证**: Ed25519 签名确保模块安全
- **持久化**: 支持 survive reboot
- **版本兼容**: 向前兼容 KernelPatch 标准

#### 2.2 模块格式
```c
struct aurora_kpm_header {
    u64 magic;              // AURORA_KPM_MAGIC
    u32 version;            // KPM version (2)
    u32 flags;              // KPM flags
    u32 header_size;
    u32 payload_size;
    char name[32];
    char version_str[16];
    u8 signature[64];       // Ed25519
};
```

### 3. 冗余保护系统 (redundancy/)

#### 3.1 健康监控
- **监控项**:
  - Syscall Hook 状态
  - SELinux 策略完整性
  - Supercall 接口可用性
  - KPM 系统状态
  - aurorad 守护进程

#### 3.2 自动恢复
- **分级响应**:
  - Healthy: 正常运行
  - Degraded: 功能降级，尝试自动修复
  - Critical: 关键故障，进入安全模式
  - Failed: 系统失效，触发恢复流程

#### 3.3 备份系统
- **备份内容**:
  - Boot 镜像
  - 模块配置
  - 应用白名单
  - SELinux 策略

### 4. 用户空间守护进程 (aurorad)

#### 4.1 架构
- **语言**: Rust
- **特性**:
  - 异步 I/O (tokio)
  - 类型安全
  - 内存安全
  - 高性能

#### 4.2 功能模块
- **Module Manager**: 模块安装/卸载/更新
- **Boot Patcher**: Boot 镜像修补
- **SUSFS Integration**: 文件系统隐藏
- **Redundancy Manager**: 健康监控和恢复
- **Event Handler**: 内核事件处理

### 5. Manager 应用

#### 5.1 技术栈
- **语言**: Kotlin
- **UI**: Jetpack Compose + View 系统混合
- **架构**: MVVM + Hilt DI
- **设计**: Material You 3.0

#### 5.2 核心功能
- **主页**: 状态卡片、快速统计、健康指示
- **模块**: 模块管理、WebUI 支持
- **配置**: 应用 Profile、权限管理
- **设置**: 主题切换、高级选项

#### 5.3 UI 特性
- **动态主题**: 跟随系统 Material You 色彩
- **动画效果**: 流畅的过渡动画
- **自适应布局**: 支持手机和平板
- **深色模式**: 完整的深色主题支持

## 工作流程

### 启动流程

```
1. 内核初始化
   └── aurora_init()
       ├── 检测功能特性
       ├── 选择 Hook 模式
       ├── 初始化钩子系统
       ├── 初始化 KPM (如启用)
       └── 初始化冗余保护

2. 早期用户空间
   └── aurorad 启动
       ├── 通过 reboot 魔法值获取 fd
       ├── 建立 Unix Socket
       └── 等待内核事件

3. 系统启动完成
   └── Manager 启动
       ├── JNI 初始化
       ├── 加载模块列表
       └── 启动 UI
```

### Root 权限获取流程

```
1. 应用请求 Root
   └── 执行 su 或通过 Manager

2. 内核拦截
   └── execve 钩子捕获
       ├── 检查 UID 在白名单
       ├── 验证 App Profile
       └── 调用 escape_with_root_profile()

3. 权限提升
   └── 修改 cred 结构
       ├── UID/GID = 0
       ├── 设置 capabilities
       └── 切换 SELinux 上下文

4. 执行代理
   └── 启动 aurorad 代理
       └── 建立 Root shell
```

## 安全设计

### 1. 多层验证
- **签名验证**: KPM 模块必须签名
- **白名单**: 应用必须授权
- **SELinux**: 严格的域切换

### 2. 安全模式
- **触发条件**:
  - 连续健康检查失败
  - 用户手动触发
  - 检测到系统不稳定

- **安全模式行为**:
  - 禁用所有模块
  - 仅保留基本 Root 功能
  - 允许系统恢复

### 3. 审计日志
- **SuLog**: 记录所有 Root 请求
- **操作日志**: 记录配置变更
- **错误日志**: 记录故障信息

## 性能优化

### 1. 内核优化
- **SID 缓存**: 加速 SELinux 检查
- **RCU 保护**: 无锁数据结构
- **延迟加载**: 非关键功能延后初始化

### 2. 用户空间优化
- **异步 I/O**: 避免阻塞操作
- **连接池**: 复用内核连接
- **缓存策略**: 减少重复查询

## 兼容性

### 1. 内核版本
- **最低支持**: Android 10 (4.14+)
- **推荐版本**: Android 12+ (5.10+)
- **GKI 支持**: 完整支持 GKI 2.0

### 2. 设备支持
- **ARM64**: 完整支持
- **x86_64**: 实验性支持
- **32位**: 有限支持

### 3. 模块兼容
- **Magisk 模块**: 部分兼容
- **KernelSU 模块**: 完全兼容
- **Aurora 原生模块**: 完整功能
